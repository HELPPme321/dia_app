DIA+ WEB APP — RUN LOCALLY

Files
- index.html: page structure and accessible controls
- style.css: phone-inspired interface, responsive layout, transitions
- script.js: navigation, product filters/search, product details, saved items, cart, and demo checkout
- assets/dia-editorial.webp: original locally stored editorial hero / product image generated for this UI

Run in Visual Studio Code
1. Extract the dia-web-app folder.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click index.html and select “Open with Live Server”.

Notes
- The app uses vanilla HTML, CSS, and JavaScript. There is no build step or backend.
- Cart items and saved favorites persist using browser localStorage.
- Checkout is a local demo flow and does not accept payment or submit personal data to a server.
- Google Fonts are optional; if unavailable, the CSS uses system sans-serif fallbacks.
